# שעון מלא (StatusClock)

אפליקציית אנדרואיד קטנה שמציגה שעון עם שניות ותאריך מלא, למשל `22:18:05  14/11/2026`,
מעל שורת המצב בפינה השמאלית העליונה.

## התקנה
1. מורידים את `StatusClock.apk` לטלפון ופותחים אותו. אם Samsung חוסמת את ההתקנה, מאשרים
   "התקנה ממקורות לא ידועים". אם ההגדרה "חוסם אוטומטי" (Auto Blocker) פעילה, צריך לכבות אותה.
2. פותחים את "שעון מלא", לוחצים על אישור "הצגה מעל אפליקציות אחרות" ומפעילים את השעון.
3. ב-Good Lock ← QuickStar ← Clock בוחרים HIDE, כדי שהשעון המקורי לא יופיע מתחת.
4. מומלץ להגדיר: הגדרות ← אפליקציות ← שעון מלא ← סוללה ← "ללא הגבלה".

## בנייה
`./build.sh` (צריך Android SDK עם platforms;android-34 ו-build-tools;35.0.0, בלי Gradle).
